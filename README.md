# ⏳ Coming Soon Countdown Page

A responsive and modern **Coming Soon** landing page featuring a real-time countdown timer built using **HTML**, **CSS**, and **JavaScript**. Ideal for announcing upcoming websites, product launches, or events.

## 🚀 Features

- **Live Countdown Timer**: Counts down to **June 1, 2025**, updating every second.
- **Responsive Design**: Fully adaptable to desktop and mobile devices.
- **Clean Aesthetic**: Gradient background, minimal layout, and clear typography.
- **Easy Customization**: Quickly modify the countdown target date or styles.

## 🛠️ Built With

- **HTML5** – Markup structure.
- **CSS3** – Styling, flexbox layout, and gradient background.
- **JavaScript (ES6)** – Countdown logic.
